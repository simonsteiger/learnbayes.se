Both collections are community-maintained, so you're more than welcome to contribute! 
Adding a new resource, for example, just requires writing a small YAML files in the [project repository](https://gitlab.com/alping/learn-bayes).
Feel free to open a merge request directly, or point us to a resource you'd like to see added by creating an issue.
