**`Learn Bayes`** was an event series at Karolinska Institutet (KI) running in Spring 2025, bringing together people interested in Bayesian statistics with international experts.
</div>

The Spring 2025 program included a [seminar series](/events/introduction-to-bayes), a [methods week](/events/bayes-in-julia-with-turing-jl), and a [networking event](/events/networking-event).
All event pages remain available in this archive.

## Organisers

The program was organised at Karolinska Institutet by [Simon Steiger](https://ki.se/en/people/simon-steiger),
[Peter Alping](https://ki.se/en/people/peter-alping),
[Marina Dehara](https://ki.se/en/people/marina-dehara),
[Paul Dickman](https://ki.se/en/people/paul-dickman), and
[Sandra Eloranta](https://ki.se/en/people/sandra-eloranta), in a collaboration between
[KEP (MedS)](https://ki.se/en/meds/research/division-of-clinical-epidemiology),
[MEB](https://ki.se/meb),
[IMM](https://ki.se/imm), and
[GPH](https://ki.se/gph),
partially funded by grants from
[SFOepi](https://ki.se/en/research/research-areas-centres-and-networks/strategic-research-area-in-epidemiology-and-biostatistics-sfoepi).
