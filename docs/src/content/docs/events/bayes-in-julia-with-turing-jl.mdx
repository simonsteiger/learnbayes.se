Xianda Sun is a PhD student working on the probabilistic programming language [Turing.jl]((https://turinglang.org/)) together with [Hong Ge](https://mlg.eng.cam.ac.uk/hong/).

In his talk Xianda will introduce Turing.jl, [JuliaBUGS.jl](https://turinglang.org/JuliaBUGS.jl/stable/) and the surrounding ecosystem, as well as showing Turing.jl incarnations of common models used in epidemiological studies.
He will also motivate the use of the Julia programming language for probabilistic programming.
