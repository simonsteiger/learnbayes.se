## Statistical rethinking: Julia

These are our own attempts at coding after Richard McElreath's examples from his [video lecture](https://www.youtube.com/watch?v=FdnMWdICdRs&list=PLDcUM9US4XdPz-KxHM4XHt7uUVGWWVSus).

<Aside title="Pluto on binder">
The links lead to interactive [Pluto](https://plutojl.org) notebooks which are hosted via a service called [binder](https://mybinder.org/).
This allows you to use buttons and sliders to change models, plots, and even try playing with the code itself!
</Aside>

More code examples from the book may follow in the future!
